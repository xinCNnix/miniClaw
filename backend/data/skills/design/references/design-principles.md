# 设计原则 — 如何避免 AI 烂设计并产出工艺

## 反 AI 烂设计规则

**禁止激进渐变背景。** 尤其紫到蓝、日落、锥形彩虹。需要背景视觉趣味时用：纯色品牌色、微妙单色渐变（<10° 色相差）、哑光纹理、全出血照片。

**禁止 emoji（除非品牌使用）。** 标题或 bullet 中的 emoji 是 AI 的标志。需要时画一个真实图标或用占位符。

**禁止圆角卡片+左边框点缀条纹。** 尤其搭配暗淡图标和渐变背景。这是全球生成最多的"仪表盘卡片"。找不同的容器隐喻 — 全出血面板、编号序列、框架单元。

**禁止 SVG 绘制代替真实资产。** 不要试图 SVG 画 hero 插画、产品截图、肖像。用占位符并请求真实素材。

**禁止 CSS 剪影充当产品照。** 用 CSS/渐变形状代表物理产品是"通用 AI 科技动画"的精确签名。

**禁止装饰性渐变球"代表 AI"。** 浮动的紫到粉渐变球是当代科技设计最滥用的符号。找不那么陈词滥调的隐喻。

**禁止过度使用的字体栈。** Inter、Roboto、Arial、system-ui 很少是正确答案。有品牌字体就用。没有就选有明确声音的搭配。不确信时问用户。

**禁止装饰性数据可视化。** 假统计、编造数字、不代表任何东西的装饰性图表 — 这些是烂设计，不是设计。

**禁止三列特性网格作为默认页面结构。** hero → 三列特性 → 推荐 → CTA 是最小阻力路径。考虑：单列编辑叙事、对比表、全出血产品 demo。

**禁止过度图标化列表。** 每项带图标的列表很少增加清晰度 — 它们增加噪音。大多数情况纯 bullet 或编号列表读得更快。

## 工艺规则

**构建前声明系统。** 在 HTML 顶部注释或可见草稿笔记中陈述：type scale、背景色、布局节奏、章节标题模式。然后遵守它。

**字号下限是真实的：**
- 1920×1080 slides：正文 ≥ 24px。标题大得多。12px 在 slides 上从后排看不到。
- 打印：≥ 12pt 正文。
- 移动：点击区 ≥ 44×44px。

**使用现代 CSS：**
- `text-wrap: pretty` 和 `text-wrap: balance` — 即时排版润色
- CSS Grid 和 `subgrid` — 真正的布局，无需 wrapper hell
- `oklch()` — 选择和谐色彩变体无需发明新色相
- Container queries — 响应容器而非视口
- `@scope` 和 `@layer` — 无特异性战争的样式
- CSS nesting — 可读的样式结构

**颜色从现有品牌/系统优先。** 有品牌文档或 token 文件就用精确 hex 值。需要派生颜色时用 `oklch()` 保持和谐。

**占位符优于伪造。** 缺少图标/logo/头像/产品截图 — 画一个标记占位符。占位符是诚实且无歧义的；伪造是分散注意力有时甚至是冒犯的。

**使用视觉节奏。** 制品从上到下/从左到右怎么读？交替重和轻的章节。给全出血图片呼吸空间。一个 deck 用 1-2 个背景色（不是 10 个）让不同背景有意义。

**匹配现有样式。** 在现有 UI 上添加时：先花一分钟观察视觉词汇。记录文案语调、色板、密度、卡片/阴影约定。然后匹配。

## 内容规则

**禁止填充内容。** 每个元素应证明自己存在的理由。不要用以下填充：
- 虚拟章节（用户没要求的"我们的价值观"、"为什么选择我们"）
- 超出展示布局所需的占位段落
- 无意义的装饰性统计/数字/图标
- 没有真实推荐的"推荐"区域

**一千个否定才有一个肯定。** 添加前问：这是因为需要，还是因为布局看起来太空？如果是后者：删掉，让现有内容更大/更粗/重新平衡。

**先问再加。** 认为额外章节/页面/文案块会加强设计时：先问用户。

**用用户的声音。** 如果他们给了文案，用他们的原话。写占位文案时匹配他们在需求中使用的语域。

**避免不必要的图标化。** 图标应澄清或标记，不是装饰。有疑问时，移除图标看是否丢失了什么。

## 设计系统思维

当用户要求一系列相关制品时，把系统当作产品：

- 整个系统选 1-2 个背景色
- 选一个 type scale（如 72/48/32/20/16/13）并只用这些精确尺寸
- 选一个间距网格（4/8/12/16/24/32/48/64）并只用这些精确值
- 选一个动态语言（相同缓动、相同持续时间范围）并复用

## 最终直觉检查

声称完成前，像从未见过一样扫视制品：
- 这看起来像是来自一个真实、特定的设计师 — 还是任何 AI 都能产出？
- 有一个明确的观点，还是我在每个决定上都打了安全牌？
- 这里有用户会记住的一个东西吗？

如果任何答案是"通用的"，重新平衡向特异性：选更大胆的颜色、提交更重的字体粗细、让 hero 更大、删除装饰性的第二章节。一个有特色的不完美制品胜过一个"安全"的易遗忘品。
