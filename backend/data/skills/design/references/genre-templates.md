# 类型特定 Mondo 提示词模板

不同电影类型在 Mondo 另类海报风格中的定制提示词结构。

---

## 恐怖 Horror

### 视觉方法
- 氛围优于血腥，阴影与负空间，孤立元素（手、眼、武器），哥特建筑

### 配色
- **经典**: 黑色、血红色、奶油色
- **哥特**: 勃艮第红、金色、旧纸色
- **心理**: 青绿、铁锈色、灰白
- **超自然**: 紫色、绿色、黑色

### 模板
```
[恐怖元素] in Mondo horror poster style, [孤立/氛围构图],
Gothic [建筑或自然元素], [2-3 色配色], vintage [年代]
horror aesthetic, screen print with halftone shadows, [氛围: 恐惧/悬念/恐怖],
minimalist symbolic approach, 暗示优于直接展示
```

### 示例：心理恐怖
```
Fragmented mirror reflecting distorted eye in Mondo horror poster style,
geometric shattered composition, 2-color print: rust orange and teal,
negative space creating unsettling gaps, vintage 1970s psychological
thriller aesthetic, visual representation of broken psyche
```

## 科幻 Science Fiction

### 视觉方法
- 几何与技术精度，巨大尺度对比，象征性技术，复古未来主义

### 配色
- **太空歌剧**: 海军蓝、银色、红色点缀
- **赛博朋克**: 霓虹粉、电蓝、黑色
- **外星接触**: 青绿、橙色、奶油色
- **反乌托邦**: 灰色、铁锈、毒黄

### 模板
```
[科幻图标: 头盔/飞船/行星] in Mondo science fiction poster style,
[几何/技术构图], [复古年代] futurism aesthetic, [冷色+点缀],
screen print with precise line work, [尺度或孤立主题],
vintage [60s/70s/80s] sci-fi poster
```

### 示例：太空探索
```
Astronaut helmet reflecting alien twin suns in Mondo sci-fi poster style,
centered symmetrical composition, duotone orange and deep blue, retro 1970s
futurism, screen print with precise technical details, sense of isolation
and discovery, vintage golden age sci-fi aesthetic
```

## 黑色电影 / 犯罪 Film Noir / Crime

### 视觉方法
- 高对比阴影，百叶窗阴影、雨效果，剪影和冒烟的枪，都市建筑

### 配色
- **经典黑色**: 黑色、白色、红色点缀
- **新黑色**: 青绿、品红、黑色
- **犯罪惊悚**: 海军蓝、琥珀、奶油色

### 模板
```
[黑色元素: 侦探/枪/城市] in Mondo film noir poster style, high contrast
[阴影技术], urban [天际线/巷道] setting, [限 2-3 色配色],
vintage [1940s/50s] crime poster aesthetic, screen print with dramatic shadows,
[mood: 愤世嫉俗/危险/神秘], minimalist hardboiled style
```

## 西部 Western

### 视觉方法
- 广阔景观地平线，孤影对大天，象征性武器，西南部配色，日落剪影

### 配色
- **经典西部**: 焦橙、土棕、奶油色
- **意大利面西部**: 红色、黑色、棕褐
- **修正主义**: 柔和大地色调

### 模板
```
[西部图标: 牛仔/景观/武器] in Mondo Western poster style, [广阔水平构图或孤独剪影],
Southwestern [景观元素], [暖色大地色调配色], vintage [1960s/70s] Western poster
aesthetic, screen print with paper texture, [mood: 史诗/孤独/暴力]
```

## 动作 / 惊悚 Action / Thriller

### 视觉方法
- 动态角度和运动线，爆炸瞬间定格，武器和车辆为焦点，大胆对角构图

### 配色
- **80s 动作**: 红色、蓝色、黄色
- **间谍**: 黑色、银色、红色
- **现代惊悚**: 橙色、青绿、黑色

### 模板
```
[动作元素: 爆炸/追车/武器] in Mondo action poster style, [动态对角或爆炸构图],
[大胆对比色], vintage [年代] action poster aesthetic, screen print with
motion blur effect, [高能氛围], geometric energy, minimalist maximum impact
```

## 奇幻 / 冒险 Fantasy / Adventure

### 视觉方法
- 史诗尺度，神话生物剪影，魔法元素（发光物体），城堡/景观宏伟

### 配色
- **高奇幻**: 紫色、金色、森林绿
- **剑与魔法**: 红色、黑色、银色
- **冒险**: 大地色调 + 魔法蓝

### 模板
```
[奇幻元素: 城堡/生物/神器] in Mondo fantasy poster style, [史诗尺度或旅程构图],
[魔法光效], [丰富饱和配色], vintage [1970s/80s] fantasy poster aesthetic,
screen print with mythical grandeur, [探索/惊叹感]
```

## 喜剧 Comedy

### 视觉方法
- 俏皮构图，明亮欢快色彩，荒诞并置，复古排版突出，视觉笑料和双关

### 配色
- **脱线喜剧**: 粉色、黄色、青绿
- **黑色喜剧**: 橄榄绿、橙色、奶油色
- **讽刺**: 三原色，高饱和

### 模板
```
[喜剧元素或视觉笑料] in Mondo comedy poster style, [俏皮荒诞构图],
[明亮欢快配色], vintage [年代] comedy poster aesthetic, screen print
with whimsical details, [幽默氛围], prominent retro lettering, visual pun
```

---

## 剧情 / 独立 Drama / Indie

### 视觉方法
- 情感微妙，个人尺度优于史诗，象征性日常物品，柔和精致配色，亲密构图

### 配色
- **成长题材**: 暖日落色调
- **家庭剧**: 大地色调，柔和
- **时代剧**: 褐色，复古精确

### 模板
```
[亲密物品或瞬间] in Mondo indie drama poster style, [个人亲密构图],
[柔和精致配色], vintage [相关年代] independent film aesthetic,
screen print with subtle texture, [情感氛围: 忧郁/怀旧/希望],
handmade artisan quality
```
