### 2. 嵌入模型技术调研

**调研内容**:
- sentence-transformers 库和模型命名规范
- 多个嵌入模型的对比分析
- 模型文件结构和下载方式

**推荐的嵌入模型**:

| 模型 | 大小 | 优势 | 适用场景 |
|------|------|------|----------|
| moka-ai/m3e-base | 400MB | 轻量、快速 | 资源受限环境 |
| BAAI/bge-m3-zh | 2.3GB | 准确度高 | 生产环境 |
| Qwen/Qwen3-Embedding-4B | ~5GB | MTEB 排名第一 | 最新技术 |

**关键发现**:
- sentence-transformers 是一个库/组织，不是单个模型
- 单个嵌入模型即可支持中英文，无需下载多个
- 必需文件约 2.2GB，包含模型权重、配置、分词器等

### 3. 模型选择指导

**用户问题解答**:
1. Qwen3-Embedding vs Qwen3-VL-Embedding
   - 推荐：Qwen3-Embedding（纯文本版本）
   - 原因：项目主要处理文本数据，VL 版本是过度设计

2. 通义千问 API 收费情况
   - 新用户有免费额度
   - 按 token 计费，约 ¥0.0008-0.12/千 tokens
   - 可选择 Ollama 本地部署（完全免费）

## 技术决策

**最终推荐**:
- 开发环境：Qwen/Qwen3-Embedding-4B 或 moka-ai/m3e-base
